# RichmondAlake Memorizz

## How do I install these formulae?

`brew install richmondalake/memorizz/<formula>`

Or `brew tap richmondalake/memorizz` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "richmondalake/memorizz"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
